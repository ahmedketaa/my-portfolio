# Ahmed Mostafa | Portfolio

Personal portfolio website of Ahmed Mostafa, Full Stack Developer. It is bilingual (Arabic and English), responsive, and supports light and dark themes.

**Live:** https://ahmed-portfolio-2026.vercel.app/ar

## Features

- Arabic and English versions with automatic RTL/LTR layout (next-intl)
- Light and dark theme (next-themes)
- Smooth animations (Framer Motion)
- Fully responsive layout

## Tech stack

- Next.js (App Router), React, TypeScript
- Tailwind CSS
- next-intl, next-themes, Framer Motion, Lucide icons
- Deployed on Vercel

## Getting started

```bash
git clone https://github.com/ahmedketaa/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm start` | Run the production build |
| `npm run lint` | Run ESLint |
