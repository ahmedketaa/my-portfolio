# Portfolio Project Master Plan

## Goals

Build a **premium bilingual developer portfolio** (Arabic / English)
that highlights: - Full Stack MERN development - Programming instruction
experience - Real production projects - Strong UI/UX and performance

Target audience: **tech companies and recruiters (especially UAE / Abu
Dhabi).**

------------------------------------------------------------------------

# Core Features

## 1. Internationalization (i18n)

-   Arabic / English support
-   RTL / LTR layout handling
-   Language switcher
-   Structured translation files

## 2. Theme System

-   Dark mode
-   Light mode
-   Smooth toggle
-   Design tokens for colors and typography

## 3. Advanced UI / UX

-   Smooth micro‑interactions
-   Section reveal animations
-   Hover effects
-   Motion hierarchy
-   Scroll‑based animations (subtle)

Goal: show high frontend skill **without hurting performance**.

## 4. Premium Developer Portfolio Tricks

### Interactive Project Showcase

Each project may include:

-   Live preview inside a browser frame
-   Website displayed inside the portfolio
-   Interactive demo capability

Since projects belong to the developer, **iframe preview is allowed**.

Fallbacks: - mock browser frame - interactive screenshots - video
preview

### Fake Browser / Device Frames

Projects may appear inside: - browser frame - laptop frame - mobile
device frame

### Interactive Project Exploration

Possible interactions: - scroll simulation - tab switching - fullscreen
preview - open live project
